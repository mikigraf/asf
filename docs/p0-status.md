# P0 qualification status

This is the release-gate audit for the PRD's 14 P0 acceptance criteria. A
unit test or in-memory adapter proves a contract or algorithm; it does not by
itself qualify a production integration. As of 2026-08-22, ASF is **not
production-ready for autonomous dispatch**.

## Blocking external contracts

Runmill now exposes exact local control operations for health, Work Order
submission, run/event/evidence reads, cancellation, and outcome
acknowledgement, and the Rust contracts have been checked against the adjacent
source. Cancellation, health reconciliation, and durable bounded cursor
observation for explicit authoritative-run streams on one configured ASF worker,
terminal evidence retention for the streams that observation leaves
`TERMINAL_READY`, GitHub-backed
evidence verification, and Linear intake/source closure are daemon-wired when
their independent complete configuration groups are present.
The health activity requires stored capabilities, matching concurrency, and a
live same-generation session, but does not create them or prove
attempt-specific ctxlane authority. The remaining external release blockers
are explicit:

- Runmill cannot look up a successfully submitted run by Work Order
  idempotency key or payload digest after response loss and envelope expiry.
- The production Work Order path is not wired, and strict Work Order V1 lacks
  the full source reference, risk reasons, planner digest, command policy, and
  an explicitly named repository-policy digest.
- ctxlane lacks the exact attempt-scoped profile, principal, environment,
  policy, worker-generation, and lease-attribution readiness contract.
- Production activities remain absent for signing/submission and dispatch,
  authoritative-run stream installation/adoption and event-to-workflow
  projection/reduction, approval application, artifact-byte retrieval, and
  Runmill outcome acknowledgement. Evidence ingestion is the one exception:
  `RETAIN_RUNMILL_TERMINAL_EVIDENCE` is daemon-wired with the rest of the
  Runmill control group, and it retains the terminal bundle, ingests the signed
  evidence bundle and its artifact manifest, and schedules verification. The
  back half of the vertical — observation, evidence, verification, source
  closure — is therefore continuous in code; the front half, from accepted work
  through ctxlane readiness, Work Order signing, submission, run adoption, and
  stream installation, has no production caller at all.
- Artifact ingestion and S3-compatible storage now exist, but neither has been
  qualified against a real bucket: no external run has proved credentials,
  encryption at rest, retention policy, or the endpoint's own error behaviour.
- The external Linux matrix with real Runmill crashes, ctxlane restarts and
  leases, protected-provider ambiguity, CI edge cases, sandbox isolation, and
  dedicated workload identities has not been run.
- The wired read-only GitHub verifier and authenticated Linear
  close/reconciliation adapter still need external qualification, and ASF has
  no OTLP exporter or durable telemetry backend.

`/healthz` is a ledger probe. `/readyz` remains
healthy with no unsupported live production backlog, but fails with per-type,
per-persisted-activity-contract-identity, or exact-worker-route counts for
every obligation whose exact job type, persisted activity contract identity,
or (for scoped routes) exact worker id falls outside the installed handler
capabilities; it is not an aggregate
dependency probe or evidence that the remaining gates have passed. This
job-type/contract/worker binding is process-local: there is no durable global
reactor capability lease, and no scanner yet promotes a known-unclaimable job
into an owned attention/escalation record. The strengthened internal
cancellation, incident-lifecycle, lease, throttling-classification, and
reservation-namespace proofs above do not replace those production integrations
or external qualification runs.

## Release decision

Use the current repository for contract development, deterministic testing,
and control-plane integration work. Do not enable production dispatch until
all partial/failed rows above are independently demonstrated and this audit is
updated with immutable qualification evidence.
